## Serena, Semgrep, ast-grep и вычислительная среда

Обозначения из общего раздела: `UDR_SOFTWARE` — каталог устанавливаемых программ; `UDR_WORKSPACE` — каталог исследуемого проекта; `HERMES_HOME` — каталог профиля Hermes; `HERMES_PYTHON` — Python действующего окружения Hermes. Все пути должны быть абсолютными. Команды выполняются на целевой машине под пользователем Hermes. Windows поддерживается нативно: выполняйте отдельные команды PowerShell ниже. На macOS нужен Homebrew. Рабочие окружения ниже отделены от `HERMES_PYTHON`.

### Зависимости и установленные редакции

1. Linux (Ubuntu 24.04): `sudo apt-get update && sudo apt-get install -y python3.12-venv build-essential libcurl4-openssl-dev libssl-dev libxml2-dev r-base`. macOS: `brew install r`. В обоих случаях установите `uv` способом из общего раздела, проверьте `uv --version`, `R --version`, `node --version`, `npm --version`. Для штатного сервера TypeScript Serena требуется **Node.js ≥20** (его зависимость `typescript-language-server@5.1.3` задаёт `engines.node: ">=20"`); Ubuntu 24.04 `apt install nodejs` обычно даёт Node 18, поэтому используйте Node ≥20 из общего раздела, а не этот пакет. Для macOS, если Node не установлен общим шагом: `brew install node`. `uv` должен быть в `PATH` процесса Hermes: Serena запускает Pyright через `uvx`.
2. `mkdir -p "$UDR_SOFTWARE"`; `uv python install 3.13`; `uv venv --python 3.13 "$UDR_SOFTWARE/serena"`; `uv pip install --python "$UDR_SOFTWARE/serena/bin/python" 'serena-agent==1.7.0'`. Проверка: `"$UDR_SOFTWARE/serena/bin/serena" --version`; `"$UDR_SOFTWARE/serena/bin/serena" init`; `"$UDR_SOFTWARE/serena/bin/serena" start-mcp-server --help`. Редакция Serena 1.7.0 соответствует тегу `v1.7.0`, коммиту `949a27ef1e5fda1a6e7b561e777bcece345c6ffd`.
3. `uv venv --python 3.13 "$UDR_SOFTWARE/semgrep"`; `uv pip install --python "$UDR_SOFTWARE/semgrep/bin/python" 'semgrep==1.178.0'`; `"$UDR_SOFTWARE/semgrep/bin/semgrep" --version` → `1.178.0` (тег `v1.178.0`, коммит `2f122b2feb38cc06272b1dde5b482e85eaf3adad`). Для первичной локальной проверки без обращения к удалённому набору правил: `"$UDR_SOFTWARE/semgrep/bin/semgrep" scan --error --pattern 'eval(...)' --lang python "$UDR_WORKSPACE"`. Команда только читает исходники; результаты выводятся в терминал. Код возврата `1` означает найденные совпадения, а не сбой установки. Правила `--config p/...` требуют получения набора правил по сети; `semgrep ci` рассчитан на отдельное подключение и политику организации.
4. `npm install --prefix "$UDR_SOFTWARE/ast-grep" '@ast-grep/cli@0.45.3'`; `"$UDR_SOFTWARE/ast-grep/node_modules/.bin/ast-grep" --version` → `0.45.3` (тег `0.45.3`, коммит `979c143639e3588c31f563091e69398683ed34f0`). Пример чтения: `"$UDR_SOFTWARE/ast-grep/node_modules/.bin/ast-grep" -p 'eval($X)' -l py "$UDR_WORKSPACE"`. На Linux используйте полное имя `ast-grep`, поскольку `sg` занят системной программой `setgroups`. Запись через `--rewrite` допускается только для отдельной проверенной операции.
5. `uv venv --python 3.13 "$UDR_SOFTWARE/analysis"`; `uv pip install --python "$UDR_SOFTWARE/analysis/bin/python" 'duckdb==1.5.5'`; `"$UDR_SOFTWARE/analysis/bin/python" -c 'import duckdb; print(duckdb.__version__, duckdb.sql("SELECT 42").fetchone())'` → `1.5.5 (42,)`. Используйте этот Python для анализа данных; системный Python и `HERMES_PYTHON` не меняйте. Отдельная строковая оболочка DuckDB не обязательна: Python API исполняет SQL локально. Для R: `mkdir -p "$UDR_SOFTWARE/R-library"`; `R_LIBS_USER="$UDR_SOFTWARE/R-library" Rscript -e 'install.packages(c("languageserver","duckdb"), repos="https://cloud.r-project.org")'`; `R_LIBS_USER="$UDR_SOFTWARE/R-library" Rscript -e 'stopifnot(as.character(packageVersion("languageserver")) == "0.3.20", as.character(packageVersion("duckdb")) == "1.5.5"); print(DBI::dbGetQuery(DBI::dbConnect(duckdb::duckdb(), dbdir=":memory:"), "SELECT 42 AS answer"))'`. Эти номера проверены в текущем перечне CRAN на 26.09.2026; если зеркало уже обновилось, остановитесь и закрепите нужную архивную редакцию с проверкой зависимостей, не принимайте молча другую версию.

### Нативный Windows (PowerShell)

Установите `uv` и Node.js ≥20 по общему разделу; R установите отдельно из [официального пакета для Windows](https://cran.r-project.org/bin/windows/base/). Проверьте `uv --version`, `node --version`, `npm.cmd --version`, `Rscript --version`. Если `Rscript` отсутствует в `PATH`, добавьте каталог `bin` установленного R в пользовательскую среду и откройте новый PowerShell. `UDR_SOFTWARE`, `UDR_WORKSPACE` и `HERMES_HOME` здесь задаются переменными окружения PowerShell и указывают на абсолютные пути Windows. Убедитесь, что эти переменные и `uv`/Node/R доступны в среде процесса Hermes. Команды соответствуют тем же редакциям, что указаны выше:

```powershell
New-Item -ItemType Directory -Force $env:UDR_SOFTWARE | Out-Null
uv python install 3.13
uv venv --python 3.13 (Join-Path $env:UDR_SOFTWARE 'serena')
uv pip install --python (Join-Path $env:UDR_SOFTWARE 'serena\Scripts\python.exe') 'serena-agent==1.7.0'
uv venv --python 3.13 (Join-Path $env:UDR_SOFTWARE 'semgrep')
uv pip install --python (Join-Path $env:UDR_SOFTWARE 'semgrep\Scripts\python.exe') 'semgrep==1.178.0'
npm.cmd install --prefix (Join-Path $env:UDR_SOFTWARE 'ast-grep') '@ast-grep/cli@0.45.3'
uv venv --python 3.13 (Join-Path $env:UDR_SOFTWARE 'analysis')
uv pip install --python (Join-Path $env:UDR_SOFTWARE 'analysis\Scripts\python.exe') 'duckdb==1.5.5'
& (Join-Path $env:UDR_SOFTWARE 'serena\Scripts\serena.exe') --version
& (Join-Path $env:UDR_SOFTWARE 'semgrep\Scripts\semgrep.exe') --version
& (Join-Path $env:UDR_SOFTWARE 'ast-grep\node_modules\.bin\ast-grep.cmd') --version
& (Join-Path $env:UDR_SOFTWARE 'analysis\Scripts\python.exe') -c 'import duckdb; print(duckdb.__version__, duckdb.sql("SELECT 42").fetchone())'
```

Для R задайте библиотеку вне системного каталога: `$env:R_LIBS_USER = Join-Path $env:UDR_SOFTWARE 'R-library'; New-Item -ItemType Directory -Force $env:R_LIBS_USER | Out-Null; Rscript -e 'install.packages(c("languageserver","duckdb"), repos="https://cloud.r-project.org")'`. Проверьте версии тем же выражением `packageVersion` из шага Linux/macOS. Встроенный сервер Serena создаётся командой `& (Join-Path $env:UDR_SOFTWARE 'serena\Scripts\serena.exe') project create --language python --language typescript $env:UDR_WORKSPACE`. В `config.yaml` Hermes для Windows используйте `command: C:/ABSOLUTE/UDR_SOFTWARE/serena/Scripts/serena.exe` и путь проекта `C:/ABSOLUTE/UDR_WORKSPACE` в `args`; прямые слеши допустимы в путях Windows и не требуют экранирования YAML. Проверка: `hermes mcp test serena` и новая сессия Hermes. Семантический поиск по Python/TypeScript поддерживается нативным запуском Serena. Для Semgrep 1.178.0 опубликовано колесо `win_amd64` (x64); для Windows ARM64 этой редакции колесо не опубликовано. Совместимость остальных частей Foundation с Windows проверяется отдельно.

### Подключение Serena к Hermes

Создайте проектный конфигурационный файл Serena: `"$UDR_SOFTWARE/serena/bin/serena" project create --language python --language typescript "$UDR_WORKSPACE"` (только если `.serena/project.yml` ещё нет). В `.serena/project.yml` проверьте `language_servers: [python, typescript]` и задайте `read_only: true`; при анализе файлов R добавьте `r` после установки `languageserver` и передайте MCP-процессу через `mcp_servers.serena.env.R_LIBS_USER` абсолютный путь к `$UDR_SOFTWARE/R-library` (на Windows — соответствующий путь Windows). Для JavaScript используется ключ `typescript`. В Serena 1.7.0 Python по умолчанию использует Pyright `1.1.403`, TypeScript — `typescript-language-server` `5.1.3` и TypeScript `5.9.3`; Serena устанавливает их управляемым способом при первом запуске. Поле `languages` неверно для этой редакции; используется `language_servers`. Проектный `read_only: true` отключает инструменты редактирования внутри Serena, но сам процесс всё ещё запускается с обычными правами пользователя.

В существующий `"$HERMES_HOME/config.yaml"` **добавьте** сервер к карте `mcp_servers`, сохранив остальные разделы. Перед редактированием сохраните копию: macOS/Linux — `cp -p "$HERMES_HOME/config.yaml" "$UDR_STATE/hermes-config.before-serena.yaml"`; Windows PowerShell — `Copy-Item -LiteralPath "$env:HERMES_HOME\config.yaml" -Destination "$env:UDR_STATE\hermes-config.before-serena.yaml"`. Если копия с этим именем уже есть, выберите новое имя вместо перезаписи. В поле `command` подставьте фактическое абсолютное значение `UDR_SOFTWARE`; в поле `--project` — фактическое абсолютное значение `UDR_WORKSPACE` (если у Hermes нет соответствующих переменных окружения, буквальные `${...}` не разрешатся):

```yaml
mcp_servers:
  serena:
    command: /ABSOLUTE/UDR_SOFTWARE/serena/bin/serena
    args: ["start-mcp-server", "--transport", "stdio", "--project", "/ABSOLUTE/UDR_WORKSPACE", "--add-mode", "no-memories"]
    enabled: true
    tools:
      include: ["get_current_config", "find_file", "list_dir", "read_file", "search_for_pattern", "get_symbols_overview", "find_symbol", "find_referencing_symbols"]
```

`no-memories` — встроенный режим Serena 1.7.0: он исключает чтение, изменение и создание её файлов памяти и вводную процедуру, зависящую от памяти. Он **не** отключает память самого Hermes. В приведённом списке Hermes регистрирует только перечисленные инструменты Serena; `execute_shell_command`, изменение файлов и памяти не попадают в вызовы модели. Список Hermes и `read_only: true` Serena ограничивают вызовы и правку через Serena, но не заменяют права файловой системы. Для намеренной правки кода временно установите в `.serena/project.yml` `read_only: false`, добавьте точные имена нужных инструментов, например `replace_symbol_body` или `insert_after_symbol`, а после работы верните оба ограничения. Не добавляйте `execute_shell_command` ради чтения.

Проверка после запуска новой сессии Hermes: `hermes mcp list`; `hermes mcp test serena`; спросите у Hermes обзор символов конкретного файла Python и TypeScript и проверьте, что доступных инструментов изменения и памяти нет. `hermes mcp test` показывает заявленные инструменты сервера, а ограничение `tools.include` проверяйте именно в новой сессии Hermes. Если сервер не стартует, проверьте журнал `logs/mcp-stderr.log` внутри выбранного `HERMES_HOME`, доступность `uvx`, Node ≥20 и реальные пути. `hermes mcp list` должен содержать `serena`; наличие записи само по себе не заменяет пробу инструмента.

### Откат

Удалите из `mcp_servers` только добавленный ключ `serena` либо верните сохранённую копию конфигурации, если после копирования никто не менял файл; начните новую сессию Hermes. Если требуется удалить именно этот набор установок: `rm -rf "$UDR_SOFTWARE/serena" "$UDR_SOFTWARE/semgrep" "$UDR_SOFTWARE/ast-grep" "$UDR_SOFTWARE/analysis" "$UDR_SOFTWARE/R-library"`. Удалять `.serena/project.yml` следует только если файл создал этот шаг и в нём нет последующих пользовательских правок. Системные `R`, Node и `uv` удаляются лишь если они были установлены исключительно ради этого пакета и не используются другими программами.

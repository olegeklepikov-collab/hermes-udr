# Research tools / Инструменты исследования

| Tool | Purpose / Назначение |
|---|---|
| research_workspace | Start/status, executable plan, dispatch/completion, journal, capability inventory, draft handoff / Рабочая область и исполнение плана |
| research_source | Register retained source text and provenance / Регистрация источника |
| research_note | Source-linked analytical notes / Аналитические заметки со ссылками |
| research_finish | Save report and explicit completion status / Сохранение отчёта и статуса |
| research_fetch | Acquire original public HTTPS bytes; raw-only in Foundation mode / Получение исходных файлов |
| research_method | Inspect guides and invoke applicable methodological operations / Руководства и методы по необходимости |
| research_web_provider | List/select registered search/extract backends within profile policy / Поставщики поиска и извлечения |
| research_compare_periods | Deterministic before/after comparisons / Сравнение периодов |
| research_build_report | Structured report artifact generation / Формирование отчёта |

One post_tool_call hook records supported search events. Provider-specific crawl, research, citation and other operations remain native Hermes/MCP tools when exposed; this table is not a vendor API limit. The offline method library contains 17 primary and 61 optional reviewed operations; listing a method does not mean it is executed automatically or validates a claim's truth.

Один обработчик post_tool_call записывает поддерживаемые поисковые события. Особые режимы сервисов доступны через соответствующие инструменты Hermes/MCP. Таблица не ограничивает их API. Библиотека содержит 17 основных и 61 дополнительную рассмотренную операцию; наличие метода не означает автоматического вызова или подтверждения истинности.
